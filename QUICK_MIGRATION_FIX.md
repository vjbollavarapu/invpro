# Quick Migration Permission Fix

## The Problem

You're getting this error on production:
```
PermissionError: [Errno 13] Permission denied: '/var/www/python/invpro/shopify_integration/migrations/0003_alter_shopifyintegration_api_version.py'
```

## Quick Fix (Choose One)

### Option 1: Use the Fix Script (Easiest)

```bash
cd /var/www/invpro
bash fix_migration_permissions.sh
```

Then run migrations:
```bash
cd /var/www/invpro/apps/backend
source venv/bin/activate
python manage.py migrate
```

### Option 2: Manual Fix

```bash
cd /var/www/python/invpro/apps/backend  # or /var/www/invpro/apps/backend

# Find Django user
DJANGO_USER=$(ps aux | grep "python.*manage.py" | grep -v grep | head -1 | awk '{print $1}' || echo "www-data")

# Fix permissions
sudo chown -R $DJANGO_USER:$DJANGO_USER shopify_integration/migrations/
sudo chmod -R 775 shopify_integration/migrations/

# Pull latest code (to get the migration file)
git pull origin main

# Run migrations
source venv/bin/activate
python manage.py migrate
```

### Option 3: Create Migration Manually

If you can't change permissions right now:

```bash
cd /var/www/python/invpro/apps/backend

# Check what migrations exist
ls -la shopify_integration/migrations/000*.py

# If 0003_add_error_count.py exists, create 0004:
# If not, create 0003:

# Create the file (adjust number as needed)
sudo nano shopify_integration/migrations/0004_alter_shopifyintegration_api_version.py
```

Paste this content (adjust dependency if creating 0003 instead of 0004):

```python
# Generated by Django 5.1.1 on 2025-01-27

from django.db import migrations, models


def get_default_api_version():
    """Get default API version from environment or use default."""
    import os
    return os.getenv("SHOPIFY_API_VERSION", "2024-10")


class Migration(migrations.Migration):

    dependencies = [
        ('shopify_integration', '0003_add_error_count'),  # Change to '0002_initial' if creating 0003
    ]

    operations = [
        migrations.AlterField(
            model_name='shopifyintegration',
            name='api_version',
            field=models.CharField(
                default=get_default_api_version,
                help_text='Shopify API version used for requests',
                max_length=20
            ),
        ),
    ]
```

Then:
```bash
# Fix ownership
sudo chown $DJANGO_USER:$DJANGO_USER shopify_integration/migrations/0004_alter_shopifyintegration_api_version.py
sudo chmod 644 shopify_integration/migrations/0004_alter_shopifyintegration_api_version.py

# Run migrations
source venv/bin/activate
python manage.py migrate
```

## Verify It Worked

```bash
python manage.py showmigrations shopify_integration
```

Should show all migrations as `[X]` (applied).
